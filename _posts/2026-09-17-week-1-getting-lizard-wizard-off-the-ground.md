This week was mostly about turning **Lizard Wizard** from a pitch into an actual team project. We narrowed down the core idea around fast, momentum-based movement through the desert, while managing water, helping critters, and dealing with predators and environmental hazards.

A big part of the week was movement research. We are currently doing studies of games like **Alto’s Odyssey, HASTE, Titanfall 2, Sonic Frontiers, Warframe,** and others to figure out what makes moving fast actually feel good. HASTE is probably the closest reference to what we’re aiming for, while Alto is a good example of the more relaxing flow we want to keep. Sonic Frontiers also has really good boss battles.  
  
We also got a lot of the boring-but-important production stuff out of the way. **[Trello](https://trello.com/invite/b/6aaaa1d285c97c731ced8bbc/ATTI1071f6f6f0c2742635984ecb536f1bbbFB77336A/capstone-lizard-wizard)** is set up, Xavier **set up** the GitHub repo and now it is running, and our production blog is starting to take shape. Vivian is also wrapping up the **2D logo**, so that's exciting!  
  
One of the bigger setup tasks this week, **aside from Trello,** was organizing the Unity project so five people can work in it without constantly causing merge conflicts. I **put together** a shared folder structure, an **industry-standard** folder hierarchy for art, audio, data, scripts, scenes, documentation, etc., and each team member now has their own sandbox scene for testing and building features before anything gets moved into production. We also added some basic rules for the team, like coordinating before editing production scenes and keeping files in the right places.  
  
This setup took a little time up front, but it should save us a lot of headaches once everyone is working on different parts of the game at the same time. Every long-term project needs solid pillars for a foundation to be built upon, so it’s worth it.
